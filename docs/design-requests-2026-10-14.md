## 먼저 알아 둘 것

**앱의 정체성 (지키는 것)** — 흑백 먹 일러스트, 앱 이름 "쉼표,", 쉼표 마크, 기본 다크 테마. "사색·쉼" 한 개념으로 묶여 있다.
이번 요청은 이 톤을 **나머지 화면까지 넓히는 것**이다. 새 콘셉트를 만들지 않는다.

**차별점 (드러내야 하는 것)** — 사용자 설문(10명)에서 기존 AI 상담·캐릭터 서비스의 불만은 "답변이 피상적이고 깊이가 없다"였다.
이 앱의 답은 철학자의 원전 구절을 근거로 한다. **"근거가 있다"가 화면에서 보여야 한다** (요청 3).

**이미 바뀐 것 (Claude, 2026-10-14)**
- 로그인 화면을 가렸다. 첫 화면을 누르면 바로 홈으로 간다 (`state/auth.dart` 의 `loginScreenEnabled = false`). 로그인 화면은 디자인하지 않아도 된다
- 안 쓰는 글꼴 3개(HiMelody·Jua·NanumPenScript)와 옛 일러스트 v1 을 지웠다. release APK 59.3MB. 글꼴을 새로 넣을 때는 크기를 생각할 것 (고운바탕 2종만 16MB)

**지켜야 할 것**
1. `lib/api/`, `lib/state/`, `backend/` 는 고치지 않는다 (Claude 담당). 화면은 지금 있는 함수·필드만 쓴다
2. 화면 파일은 `import 'package:flutter/material.dart' hide Text;` + `import 'keep_words.dart';` — 한글 낱말이 줄 끝에서 쪼개지지 않게 하는 Text 다. 새 파일도 같다
3. 라이트·다크 둘 다, 글씨 크기 "아주 크게"(1.3배)까지 깨지지 않게
4. 테스트가 쓰는 key 는 그대로 둔다: `persona-<key>`, `msg-<i>`, `menu-delete`·`menu-copy`·`menu-report`, `secret`, `secret-banner`, `question`, `send`, `sources-…`, 설정의 `theme`·`text-size`·`usage`·`pay`·`signout`·`reports`, 신고 창의 `report-agree`·`report-send`·`report-detail`
5. 동작은 바꾸지 않는다 (메뉴 항목, 확인 창, 시크릿 모드 규칙, 신고 동의 체크 등). 모양만
6. 끝나면 `cd mobile && flutter analyze && flutter test` 가 깨끗해야 한다. 화면 구조가 바뀌어 테스트 기대값이 달라지면 테스트를 최소한으로 고치고, 무엇을 고쳤는지 알린다. 글 찾기는 `find.text` 대신 `test/text_finders.dart` 의 `findText`
7. 새 패키지는 사용자에게 먼저 묻는다. 커밋·푸시는 하지 않는다 (Claude 가 한다)

## 요청 1. 기능 화면을 브랜드 톤으로 통일

**지금**: 첫 화면·바둑판·소개는 먹 일러스트 톤인데, 아래 화면은 Flutter 기본 부품(Material 3 기본 목록·버튼·창) 그대로다. 화면마다 다른 앱처럼 보인다.

| 화면 | 파일 |
|---|---|
| 설정 (테마·글씨 크기·계정·사용량·결제(준비 중)·개발자 신고 내역) | `ui/settings_screen.dart` |
| 말풍선을 길게 누르면 뜨는 메뉴 (삭제·복사·대화내용 신고) | `ui/chat_screen.dart` `_showMenu` |
| 확인 창들 (질문과 답 지우기, 전체 지우기, 시크릿 끄기) | `ui/chat_screen.dart` |
| 대화내용 신고 창 | `ui/report_dialog.dart` |
| 신고 내역 (개발자만) | `ui/reports_screen.dart` |
| 시크릿 모드 안내 띠·빈 화면 | `ui/chat_screen.dart`, `ui/incognito_icon.dart` |

**요청**: 위 화면을 `app_theme.dart` 의 색·글꼴·모서리·간격 규칙에 맞춘다. 한 곳(테마)에서 정하고 화면마다 따로 칠하지 않는 쪽이 좋다.
**완료 기준**: 첫 화면 → 바둑판 → 대화 → 메뉴 → 설정을 차례로 넘겨 봤을 때 같은 앱으로 보인다.

## 요청 2. 내 질문 말풍선의 보라색 없애기

**지금**: `ui/chat_screen.dart` `MessageBubble` 의 내 질문 바탕이 `Color(0xFF7638FA)`(보라) — 앱 전체에서 유일한 원색이라 흑백 톤과 부딪힌다.
**요청**: 흑백 팔레트 안에서 내 말과 철학자의 말을 구분한다 (명도 차이·테두리·정렬 등).
**완료 기준**: 라이트·다크 모두 말풍선 글자와 바탕의 대비가 4.5:1 이상.

## 요청 3. 근거를 드러내기 (가장 중요)

**지금**: 근거는 답 말풍선 안의 접힘 줄 "근거 구절 5개"(`ui/source_tile.dart` `SourcesSection`)를 눌러야 보인다. 근거가 없을 때는 작은 글씨 "근거 구절 없음".
**요청**:
- 출처를 접지 않고 바로 보이게 한다. 예: 말풍선 아래 작은 칩 `이 사람을 보라 2:10`, `마태복음 6:25~6:34`. 많으면 2~3개만 보이고 "+3" 처럼 줄여도 된다
- 데이터는 `AskResponse.sources` 의 `Source.label`(= 한글 작품명 + 위치)을 그대로 쓴다
- 근거가 없는 답(`grounded == false`, 안전 안내 `safety == true` 제외)은 "원전에서 직접 다루지 않은 질문" 정도의 뜻이 한눈에 보이는 표시로 바꾼다. 경고처럼 보이지는 않게
**하지 않는 것**: 칩을 눌렀을 때 구절 본문·번역을 보여주지 않는다 (사용자 결정, CLAUDE.md 4.2 — 세 번 바로잡은 사항이다). 칩은 누를 수 없거나 아무 동작이 없어야 한다.
**완료 기준**: 답을 처음 봤을 때 접힘을 열지 않아도 어디서 나온 말인지 보인다.

## 요청 4. 바둑판 카드에 이름, 빈칸 없애기

**지금**: `ui/persona_grid_screen.dart` — 카드에 초상만 있고 이름이 없다(누군지 얼굴로 알아야 한다). 3명을 2열에 놓아 오른쪽 아래가 빈다.
**요청**:
- 카드에 이름을 넣는다. 한 줄 소개(`Persona.blurb`)도 넣으면 좋다
- **2열은 사용자가 정한 것이다 (2026-10-10)** — 유지하되 빈칸이 안 생기게 한다. 예: 세 번째 카드를 두 칸 너비로
**완료 기준**: 처음 보는 사람이 이름을 읽고 고를 수 있고, 빈칸이 없다. `persona_grid_test.dart` 의 "2열" 시험이 레이아웃에 맞게 통과한다.

## 요청 5. 대화창에서 철학자가 보이게

**지금**: 대화창 안에서는 철학자가 제목 글자로만 있다. 답을 기다리는 5~9초 동안 기본 스피너와 "답을 찾는 중…"만 뜬다 (`ui/chat_screen.dart`).
**요청**:
- 철학자의 답 말풍선 옆(또는 위)에 작은 초상. 일러스트는 이미 있는 것(`PersonaVisual`, `portrait_ink.dart` 의 그림)을 잘라 쓴다. 새 그림을 만들지 않는다
- 기다리는 표시를 철학자 이름이 들어간 조용한 표시로 (예: "니체가 생각하는 중"). 요란한 애니메이션은 피한다
**완료 기준**: 대화창 캡처 한 장만 봐도 누구와 대화하는지 알 수 있다.
